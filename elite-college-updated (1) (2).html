📱 Kaise Kaam Karta Hai

1. Admin apna naam + password daal kar login karta hai. Us ka record (naam, device, waqt) save ho jata hai.

2. Naya Admin pehle Approval Pending mein aata hai — jab tak Head Admin Approve na kare, wo andar nahi ja sakta.

3. Head Admin dekh sakta hai kis Admin ne login kiya, kis device se, aur kitni der pehle.

4. Head Admin kisi bhi Admin / Viewer ko Deactive kar sakta hai — us ka system foran lock ho jata hai.

5. Admin sirf data manage kar sakta hai, devices control nahi kar sakta.
